A developer needs to query a relational database from an AWS Lambda function. The Lambda function will be called frequently. The developer needs to avoid the latency introduced by the initial JDBC connection to the database in subsequent invocations of the Lambda function. ## Answer

**B**

- **B) **
  - The Lambda environment can reuse the same database connection for subsequent invocations when defining the database connection details in the code but outside the handler method.

## Why the other options are incorrect

- **A) **
  - Database connection details can be stored as an environment variable.
  - However, the developer still needs to initialize the connection within the code for the connection to be used in queries.

- **C) **
  - Database connection details can be stored in Systems Manager Parameter Store.
  - However, initializing the connection within the handler method will result in it re-initializing each subsequent Lambda function invocation.

- **D) **
  - Initializing the connection within the handler method will result in it re-initializing each subsequent Lambda function invocation.
