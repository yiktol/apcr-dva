The data is sometimes retrieved using a known key, and sometimes the key is not known, resulting in multiple items being returned. ## Answer

**C**

- **C) **
  - Set the limit parameter to 1 to set the maximum number of items that need to be retrieved with a DynamoDB scan operation.

## Why the other options are incorrect

- **A) **
  - The parallel scan operation can logically divide a table into multiple segments, with multiple application workers scanning the segments in parallel.
  - Parallel scan returns the same number of results as an ordinary scan, except the results can be returned more quickly.
  - Parallel scan does not limit the number of items returned.

- **B) **
  - A filter expression applies additional matching criteria to limit the items returned.
  - This expression does not provide a specific limit on the number of items returned.

- **D) **
  - The page-size parameter will determine the number of items returned in each page of a query.
  - This method is only relevant for queries that involve the key.
