# Picking the right database option

Picking the right database option

- A) Aurora is a relational database (not a key-value database). Aurora is not likely to achieve microsec
- B) DynamoDB is a NoSQL database that supports key-value records. DAX delivers response times in microse
- C) Aurora is a relational database (not a key-value database). Aurora is not likely to achieve microsec
- D) Neptune is a graph database that is optimized for working with highly connected data. Neptune is not

## Answer

**B**

- **B) **
  - DynamoDB is a NoSQL database that supports key-value records.
  - DAX delivers response times in microseconds.

## Why the other options are incorrect

- **A) **
  - Aurora is a relational database (not a key-value database).
  - Aurora is not likely to achieve microsecond latency consistently.

- **C) **
  - Aurora is a relational database (not a key-value database).
  - Aurora is not likely to achieve microsecond latency consistently, even with ElastiCache.

- **D) **
  - Neptune is a graph database that is optimized for working with highly connected data.
  - Neptune is not optimized for simple key-value data.
