About the certification

Build, deploy, and debug on AWS

The AWS Certified Developer – Associate (DVA-C03) validates the ability to build, deploy, debug, and maintain cloud-native applications on AWS — covering core AWS services, application lifecycle management, and the use of the AWS CLI and SDKs to interact with AWS services from code.

Who it's for: developers with hands-on experience building and maintaining applications on AWS who are working toward (or refreshing for) the Developer – Associate exam.
